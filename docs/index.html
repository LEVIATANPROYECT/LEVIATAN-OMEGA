01 / LA PREGUNTA

El resultado real
es la obra.

¿Qué genera una idea cuando su propagación depende de aportaciones voluntarias? Cada aportación aceptada puede abrir hasta diez invitaciones. Una cadena puede crecer, transformarse o terminar.

Durante 168 horas se reciben contribuciones. Las siguientes 48 horas sirven para terminar la moderación y las apelaciones. No hay resultados mínimos ni participantes simulados.

La genealogía registra relaciones entre aportaciones. No verifica identidades humanas únicas. La IA solo interviene por indicación de una persona; no hay autorreplicación ni difusión masiva automatizada.

1.000.000 €

Precio de salida previsto del original autenticado. No es una tasación ni una venta garantizada. Participar no da derecho a remuneración ni a una parte de una eventual venta.

03 / APORTAR

Una invitación.
Tu contribución.

Puede ser una crítica, una idea, una investigación, código o una transformación. Cuestionar el proyecto también forma parte de él.

Necesitas una invitación privada y una cuenta de GitHub. Los envíos y tu cuenta serán visibles allí. Usa un seudónimo y no incluyas información personal innecesaria.

Condiciones y licencia ↗
Privacidad y retirada ↗

Abre el archivo privado que descargaste al preparar el compromiso. No lo publiques ni lo compartas: contiene tus futuras invitaciones.

Espera a que GitHub confirme COMMIT_CAPTURED. Después revela con la misma cuenta, antes de 24 horas y del cierre general.

Abrir GitHub ↗

Pega el texto completo en el cuerpo del nuevo issue y pulsa Create. No edites el envío después de crearlo.
